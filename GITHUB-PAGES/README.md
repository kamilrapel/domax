# Strona DOMAX Wadowice

Statyczna strona firmy DOMAX (osłony okienne, Wadowice).
Publikowana przez GitHub Pages z gałęzi `main`, katalog główny.

Plik `.nojekyll` jest wymagany - bez niego GitHub pomija katalog `_astro`
ze stylami i strona wyświetla się bez formatowania.

Źródła do edycji treści: osobne archiwum `zrodla-astro.zip`.
